# Changelog

User-affecting changes only: flake outputs, module options, helper function arguments, runtime behavior, and supported bundle structures. Internal implementation details, refactors, and test fixtures stay in `git log`; this file is where a user learns what moved between builds.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versioning follows CalVer (`YYYY.MM.DD`): each tagged release owns a dated section, and changes that have landed on `main` since the last tag accrue under Unreleased.

## [2026.09.22]

### Added

- **`config.lib.appIdentity`**: the home-manager and nix-darwin modules now expose `stabilizeApp` and `mkAppBundle` as `config.lib.appIdentity`, so a module that owns a package option (e.g. `programs.kitty.package`) or a launchd agent can stabilize without calling `pkgs.callPackage inputs.nix-mac-app-identity { }` itself. Both routes build the same derivation. ([b06b60b](https://git.natsukium.com/natsukium/nix-mac-app-identity/commit/b06b60b4877d188290841d81fb369a3c236ceacf))

### Fixed

- **Wrapped executables (`makeBinaryWrapper`)**: applications wrapped with `makeBinaryWrapper` (such as `pkgs.flameshot` and `pkgs.kitty`) now retain their TCC permissions across rebuilds. Previously, `Contents/MacOS/<app>` was an entrypoint stub that executed an inner `.app-wrapped` binary pointing to the original Nix store path, leaving the actual running executable unsigned and tied to a volatile store path. All Mach-O binaries under `Contents/MacOS` are now signed with the bundle's designated requirement (`identifier "<bundle-id>"`). ([598399b](https://git.natsukium.com/natsukium/nix-mac-app-identity/commit/598399b6f0a70846dbf5ad0e0ef4701819019f79))
- **Internal store path references**: references to the source derivation's store path in bundle wrapper scripts, text files, and Mach-O binaries are rewritten to the stabilized output path before signing. This prevents stabilized binaries and wrappers from executing or referencing code in the original unstabilized store path. ([598399b](https://git.natsukium.com/natsukium/nix-mac-app-identity/commit/598399b6f0a70846dbf5ad0e0ef4701819019f79))
- **Duplicate binaries in `bin/`**: when a package provides a binary in `bin/` that duplicates one in `Contents/MacOS/`, it is replaced with a relative symlink into the bundle rather than remaining an independent copy, ensuring both share the bundle's stable identity. ([598399b](https://git.natsukium.com/natsukium/nix-mac-app-identity/commit/598399b6f0a70846dbf5ad0e0ef4701819019f79))

### Changed

- **Derivation output naming**: stabilized derivations now preserve the source package's store name (keeping paths equal in length for in-place Mach-O rewriting), with `pname` set to `<name>-stable-identity`. Standalone bundles generated by `mkAppBundle` are named `<App>.app`. ([598399b](https://git.natsukium.com/natsukium/nix-mac-app-identity/commit/598399b6f0a70846dbf5ad0e0ef4701819019f79))
- **Bundle validation**: bundles containing directory symlinks inside `Contents/MacOS`, symlinks into nested bundles, or filenames containing `:` or `@` are rejected at build time. Nested bundles (`.plugin`, `.framework`) retain their own bundle identifiers. ([598399b](https://git.natsukium.com/natsukium/nix-mac-app-identity/commit/598399b6f0a70846dbf5ad0e0ef4701819019f79))

## [2026.09.19]

### Added

- **`stabilizeApp`**: helper to stabilize macOS GUI applications (`.app`) built by Nix. Re-signs ad-hoc application bundles under a designated code requirement (`identifier "<bundle-id>"`) so macOS TCC permission grants (Accessibility, Input Monitoring, Microphone, etc.) persist across Nix rebuilds instead of invalidating on `cdhash` changes.
- **Vendor signature pass-through**: applications carrying an authentic Apple Developer ID signature are detected and passed through untouched, preserving their existing Team ID requirements.
- **`allowUnsupported` option**: passing `{ package = pkgs.foo; allowUnsupported = true; }` to `stabilizeApp` allows unsupported bundles (such as those containing shell scripts in `Contents/MacOS`) to emit a build warning and pass through untouched rather than failing the build.
- **`mkAppBundle`**: helper to wrap bare executables (daemons and CLI utilities) into a minimal `.app` bundle. Grants them a bundle identifier and Mach-O structure recognized by macOS TCC, while providing a CLI symlink under `$out/bin/<mainProgram>`. Applications are hidden from the Dock by default, with `showInDock = true` available for GUI applications.
- **Nix modules**:
  - `homeManagerModules.default`: Home Manager module (`targets.darwin.appIdentity.apps`) to automatically stabilize applications before copying or linking them to `/Applications`.
  - `darwinModules.default`: nix-darwin module (`system.appIdentity.apps`) for system-wide application stabilization.
- **Diagnostics (`flake apps`)**:
  - `tcc-watch`: live monitor that streams TCC decision events from the macOS unified log (`com.apple.TCC`) without requiring Full Disk Access.
  - `tcc-dump`: inspection tool to dump stored TCC grants and decode raw code requirement blobs into text (requires Full Disk Access).
